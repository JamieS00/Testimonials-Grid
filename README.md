### What I learned

This project was one of the hardest layouts I’ve worked on because I relied heavily on Flexbox. I realized Flexbox alone wouldn’t achieve the design correctly, so I had to learn and use CSS Grid more deeply. Through this project, I gained a much better understanding of Grid layouts, positioning, and responsive design.

### Continued development

Moving forward, I want to keep practicing CSS Grid and become more comfortable using it alongside Flexbox. This project showed me how Grid can be helpful for placing items in specific positions within a layout, while Flexbox is still useful for alignment and one-dimensional layouts.
